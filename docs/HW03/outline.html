寫章時要處理的 repo 問題

讀程式時找到、會變成 warn 框或練習題的地方。每一條都會在對應的章節實測或逐行指出。

  1. log 檔永遠是空的：train.py:180-184 用 with open(..., "a"): 打開檔案，但裡面的 print 沒有給 file=，所以字印到螢幕上，sample_log.txt 是 0 bytes；每個 epoch 的驗證結果也因此在螢幕上印兩次。→ 第 4 章
  2. epoch 編號不一致：train.py:188 印 Best model found at epoch {epoch}，用的是從 0 起算的 epoch；同一個 epoch 的其他行用 epoch + 1。→ 第 0、4 章
  3. 驗證集被打亂：train.py:64 的 valid_loader 是 shuffle=True，準確率是「各 batch 平均再平均」，最後一批只有 102 張卻和 256 張的批同權重。實測偏差很小（±0.2 個百分點），但它會消耗亂數。→ 第 4 章
  4. others.py 不能執行：它用了 transforms 卻沒有 import，也沒有任何程式 import 它；它只是報告兩題的空白模板。→ 第 6、7 章
  5. super(FoodDataset).__init__() 寫錯：少了 self，呼叫的不是 Dataset.__init__；剛好沒有影響。→ 第 1 章
  6. Resize 壓扁圖片：多數原圖是 512×512 或 512×384，Resize((128, 128)) 不保留長寬比。→ 第 2 章
  7. 不能宣稱過了 Kaggle 基準線：驗證準確率不等於 Kaggle 測試集分數，只能說「驗證集上的位置」。→ 第 0、8 章
