A.5　關鍵數字一覽

資料（第 1 章）

  • training 9,866 張（663 MB）、validation 3,430 張、test 3,347 張，全部 RGB 的 JPEG；train : val ≈ 2.9 : 1。
  • 每類（training）：麵包 994、乳製品 429、甜點 1,500、蛋 986、炸物 848、肉類 1,325、麵食 440、米飯 280、海鮮 855、湯 1,500、蔬果 709。驗證集每類約為訓練集的 1/3。
  • training 有 542 種圖片大小，512×512 有 5,551 張；最小 270×207，全部三份裡最大 9216×6144。
  • 訓練集經 test_tfm 的 RGB 平均 0.5549／0.4509／0.3436，標準差 0.2668／0.2694／0.2766（第 2 章）。

模型（第 0、3、7 章）

  • Classifier：12,833,803 個參數；卷積部分 3,913,728，全連接 8,920,075，fc 第 1 層 8,389,632（65%）；buffer 2,949 個；checkpoint 51,360,932 bytes。
  • 一張圖約 1,094,194,688 次乘加，99% 在卷積；感受野 94、跨距 32。
  • Residual_Network：68,259,147 個參數，fc 第 1 層 67,109,120（98.3% 在 fc_layer）。

訓練與預測（第 0、2、4、5 章）

  • batch 數：訓練 39（最後一批 138）、驗證 14（最後 102）、測試 14（最後 19）；原版 batch 64 時訓練 155 個。
  • train.py 5 個 epoch：3 分 0.70 秒、CPU 1723%；最佳第 5 個 epoch，印出 0.55541、真實 0.55394（1,900／3,430）。印出值和真實值的差在 ±0.2 個百分點內。
  • 一個 epoch 的訓練約 28 秒裡，GPU 只算 5–6 秒；只讀圖：num_workers 0／4／8 為 22.5–24.8／4.2／2.7 秒。
  • 第 1 個 epoch 之後同一份權重：eval 模式 0.17697、train 模式 0.39679（BatchNorm 的 running_var 還殘留 0.939 = 0.0164）。
  • 梯度長度：前 5 個 epoch 最大 9.962，max_norm=10 從沒觸發；Q2 殘差網路初始就是 48.90。
  • 驗證集各類 recall（sample_best.ckpt）：最差米飯 0.208、甜點 0.228，最好湯 0.802。

A.6　repo 問題清單

讀程式時找到的地方，本 repo 照原樣保留、沒有修。多數是原版 notebook 就有的寫法。

一、會影響結果或可重現性的

  1. 驗證集被打亂、準確率「各批平均再平均」（train.py:64、172-173）：最後一批 102 張被多給了權重，印出的值晃動約 ±0.2 個百分點，可能讓最佳 epoch 選錯。→ 第 4 章
  2. tqdm.auto 改變亂數順序（train.py:19、96、146）：在腳本裡是 tqdm_asyncio，每個迴圈多建一個 DataLoader 迭代器；加不加進度條、num_workers 多少，訓練結果都會不同（num_workers=4 時第 5 個 epoch 0.48967 對 0.55541）。→ 第 4 章
  3. PyTorch 預設 24 條執行緒拖慢讀圖：ToTensor 與 collate 用掉約 40 倍的 CPU 時間；OMP_NUM_THREADS=1 讓 train.py 快 18%，結果不變。→ 第 2 章

二、潛在錯誤（目前碰巧沒出事）

  1. test.py:35 的 .squeeze()：某一批只剩 1 張時 tolist() 回傳 int，prediction += int 出錯；本 repo 最後一批 19 張。→ 第 5 章
  2. Id 不是從檔名來的（test.py:44）：靠檔名連續、補零、shuffle=False 才對得上；任何一個不成立都不會報錯。→ 第 5 章
  3. test_tfm 定義了兩次（train.py:44-47、test.py:15-18）：改了一邊忘了另一邊不一定會報錯。→ 第 5 章
  4. 光溜溜的 except:（dataset.py:34）：取標籤失敗一律給 -1，commit 381aad0 之前的 Windows 寫法在 Linux 上就是這樣讓每張訓練圖都變成 -1，要到算 loss 時才出錯。→ 第 1 章
  5. super(FoodDataset).__init__()（dataset.py:15）：少了 self，沒有呼叫到 Dataset.__init__；剛好 Dataset 沒有自己的建構子。→ 第 1 章
  6. 給了 files 仍然 os.listdir(path)（dataset.py:17-20），印出的路徑也是 path 而不是實際的檔案來源。→ 第 1 章

三、寫法與註解（不影響執行）

  1. log 檔永遠是空的（train.py:180-184）：with open(...) 沒有 as f、print 沒有 file=f，結果印到螢幕上兩次。→ 第 4 章
  2. Best model found at epoch {epoch} 從 0 起算（train.py:188），其他行用 epoch + 1。→ 第 4 章
  3. others.py 不能執行：用了 transforms 卻沒有 import，也沒有程式 import 它。→ 第 7 章
  4. 過時的註解：train.py:60 提到不存在的 loader 參數；train.py:138 提到這個模型沒有的 dropout；train.py:171 說「記錄值的平均就是整個驗證集的平均」，不完全對。→ 第 0 章、第 4 章
  5. 沒有作用的設定與 import：patience = 300 在本書的實驗裡都走不到；grad_norm 存了沒用；test.py 的 ConcatDataset、Subset、DatasetFolder 等沒用到；卷積接 BatchNorm 時卷積的 1,472 個 bias 沒有作用。→ 第 3 章、第 4 章、第 5 章

四、投影片和現在的差異

  1. 「CrossEntropyLoss 不支援多個標籤」（投影片第 11 頁）：PyTorch 1.10 起支援機率標籤，實測和手寫公式相同。→ 第 6 章
  2. 類別名稱：repo 與投影片都沒有寫 11 類是什麼，名稱出自原始的 Food-11 資料集。→ 第 1 章
