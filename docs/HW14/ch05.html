第 5 章　MAS：不用 label 的重要度（作業的 TODO）

Memory Aware Synapses 換了一個問題來問重要度：不問「這個參數動了，舊任務的 loss 會變多少」，而問「這個參數動了，模型的輸出會變多少」。輸出不需要 label，所以 MAS 可以用沒有標註的資料估計重要度。這份作業唯一要學生自己寫的程式就是 MAS 的重要度。這一章逐行讀本 repo 的寫法、量它算出來有多大，再解釋為什麼 MAS 在第 0 章的成績表上贏了：它記得最多，代價是新任務學得最差。

5.1　想法：輸出對參數有多敏感

把學完任務 A 的模型看成一個函數 F(x; θ)：輸入一張圖，輸出 10 個 logits。如果某個參數 θi 稍微變動 δ，輸出會變多少？一階近似是 F(x; θ + δ) − F(x; θ) ≈ Σi gi(x) · δi，其中 gi(x) 是輸出對 θi 的梯度。梯度的大小就代表「這個參數對輸出有多大影響」：影響大的參數，學新任務時就不要動它，學到的那個函數才會保持原樣。

輸出是 10 維的向量，要變成一個數才能取梯度。MAS 論文用的是輸出的 L2 範數的平方 ‖F(x)‖²，對每個樣本取梯度的絕對值，再對所有樣本平均：

Ωi = (1/N) Σk=1..N | ∂ ‖F(xk; θ)‖²2 / ∂θi |

和 EWC（第 4 章）比，有三個差別：

  • 不需要 label：整個式子裡只有輸入 xk 和模型的輸出。EWC 要算 log p(y | x)，需要 y。所以 MAS 可以用任何手邊的輸入資料估計重要度，包括沒有標註的資料，也可以在部署之後用測試時遇到的輸入持續更新。投影片 p.20 問「這個方法需不需要 label」，答案是不需要。
  • 取絕對值、不平方：EWC 把梯度平方（Fisher 的定義），MAS 取絕對值。
  • 對象是輸出，不是 loss：‖F(x)‖² 不是模型訓練時要最小化的東西，模型訓練好之後它的梯度並不會變成 0。5.3 節會看到這一點讓 MAS 的重要度比 EWC 大了將近一百萬倍。

notebook 的 MAS 說明還提到兩個版本：論文提出的是 local 版，對每一層的輸出各取一次 L2 範數平方，只用來算那一層參數的重要度（論文指出這個版本等價於一種 Hebbian 學習規則：兩端神經元同時被強烈活化的連結比較重要）；作業要求的是 global 版，只用最後一層的輸出，一次 backward 就得到所有參數的重要度。

和論文的公式比，這裡同樣是「先對 batch 平均，再取絕對值」，而不是逐樣本取絕對值再平均（第 4 章 4.3 節 EWC 的同一個問題）。下一節會量這個差別有多大。

幾種常見的寫法，結果是否相同

  • output.norm(2, dim=1).pow(2).mean()：先算 L2 範數再平方，和第 54 行數學上相同。
  • 把 mean() 換成 sum()：重要度變成 128 倍（每個 batch 的梯度是 128 張圖的和），方法本身相同，但等於把 λ 放大了 128 倍；照作業的 λ = 0.1 跑，結果會不同（5.4 節：λ 大十倍，ACC 就從 83.88 掉到 78.66）。本書沒有實際跑這個寫法。
  • 把 abs() 換成 ** 2：這就不是 MAS 了，變成「對輸出平方和取 Fisher 式的平方」，大小與排序都會改變。
  • 用 F.mse_loss(output, torch.zeros_like(output))：它會再除以 10（對類別也取平均），重要度是第 54 行的十分之一。

投影片 p.32 說明：MAS 的 TODO 沒寫，只要學習曲線畫對，報告的第一部分仍然給分；也就是 TODO 留著 pass 時程式照樣能跑，MAS 的重要度只是一直維持 0，等於 λ = 0.1 的 baseline。

5.3　MAS 的重要度有多大

第 0 章的成績表後面提過：EWC 的重要度加總是 0.44，MAS 的是 44 萬。為了把原因量清楚，本書用 docs/tools/hw14_mas_omega.py 在第 4 章同一個模型上（只學過任務 1、種子 0）比較三種重要度：

本 repo 的 TODO：batch 平均 ‖F(x)‖² 的梯度取絕對值406,35370.06205,466110,15368,92521,809
論文的定義：每張圖的梯度取絕對值再平均735,03272.97335,251217,666136,20545,910
對照：EWC（methods/ewc.py 的算法）0.4534.83e-4（第 4 章 4.3 節）

三件事：

  • 先平均再取絕對值，只讓 MAS 變小 1.8 倍（EWC 是 111 倍）。兩者的 Pearson 相關係數 0.867，Spearman 0.936，排序大致相同。差距小的原因在 5.1 節：‖F(x)‖² 不是訓練時最小化的目標，模型訓練好之後，各張圖的梯度方向並不互相抵消。
  • MAS 的重要度是 EWC 的約 90 萬倍（406,353 ÷ 0.453）。有三個原因疊在一起：輸出平方和本身很大（這個模型在任務 1 訓練資料上的 ‖F(x)‖² 平均 399、中位數 350），它的梯度也大；取絕對值不會像平方那樣把小於 1 的梯度壓得更小；batch 平均不會把它抵消掉。
  • 但兩者對「哪個參數比較重要」的看法相當一致：MAS 與 EWC 重要度的 Spearman 相關係數 0.861（Pearson 只有 0.427，因為兩者的分布形狀不同，少數極大值的位置不一樣）。也就是說，兩種方法挑出的「重要參數」大致是同一批，差最多的是大小。

所以第 0 章 EWC 的 λ = 100 和 MAS 的 λ = 0.1 看起來 MAS 小一千倍，實際上 MAS 的懲罰項強了將近一千倍（44 萬 × 0.1 對 0.44 × 100）。比較兩者時，比的主要是「懲罰的強度」，不是「重要度的估計方法」。

這張表是穩定性（stability）與可塑性（plasticity）取捨最清楚的例子：

  • λ 越大，新任務越學不會。對角線平均從 98.22 降到 88.57；λ = 1 時任務 5 剛學完只有 75.37。重要度是一個任務一個任務累加起來的（加上第 4 章 4.4 節的重複累加），越後面的任務被拉得越緊，所以對角線越往後掉得越多。
  • 舊任務記得最多的地方不在 λ 最大。λ 從 0.1 加到 1，BWT 幾乎不變（−12.32 對 −12.39），任務 1–4 最後的平均反而從 82.69 降到 79.48：參數被拉住了，但被拉住的是「沒學好的權重」，每個任務剛學完就不高，也沒有多少東西好記。
  • ACC 在中間最高。λ = 0.1 時 83.88。作業的設定剛好落在這組掃描的最佳點，但這只代表在 0.001、0.01、0.1、1 這四個值裡它最好，更細的掃描本書沒有做。

λ = 0.1 時五個種子的 ACC 是 83.88、82.53、82.45、82.56、83.95，平均 83.07 ± 0.77；BWT −13.72 ± 1.15；對角線平均依序是 97.75 / 96.40 / 94.47 / 92.05 / 89.60。換種子之後，「MAS 記得多、學得差」的樣子完全一樣。

修正重複累加（C 組，--guards latest）之後，λ = 0.1 的 ACC 是 82.76，比原版的 83.88 略低，落在五個種子的範圍內（82.45–83.95）。修正讓後面任務的重要度變小（任務 5 結束時總和 164.8 萬，原版 634.1 萬），任務 5 的對角線回到 91.43（原版 88.64），任務 1–3 的最後準確率則略降。對 MAS 來說，重複累加剛好起了「越後面拉越緊」的作用，修不修差別不大。

5.5　MAS 為什麼在第 0 章贏了

把這一章和第 4 章放在一起看，第 0 章成績表上「MAS 83.06、EWC 71.66」的差距，主要不是因為 MAS 的重要度估計比 EWC 好，而是：

  1. MAS 的重要度在數值上大了約 90 萬倍（5.3 節），而 λ 只小了一千倍，懲罰項實際上強了將近一千倍；
  2. EWC 在 λ = 100 時幾乎沒有懲罰（第 4 章 4.5 節），調到 λ = 10000 之後 ACC 也到了 80.75；
  3. 兩者對重要參數的排序大致相同（Spearman 0.861）。

要公平地比較方法，每個方法都要用同樣的程序選 λ。持續學習的文獻常見的做法是：只用前幾個任務（或另外切出來的驗證集）調超參數，再用調好的值跑完整個序列，避免拿測試結果挑 λ。第 8 章把五種方法在 B 組掃描裡的最佳值並排比較，並提醒這仍然是「用測試結果挑 λ」，數字會偏樂觀。

現在的做法：不用 label 的重要度，和「先調好 λ 再比」

MAS「只看輸出、不看 label」的性質，在 label 稀少或資料是串流的情境特別有用；後來也有研究把同樣的想法用在大型語言模型上，用模型對一般文字的輸出敏感度，估計哪些參數承載了通用能力，微調時對它們加懲罰或乾脆不更新。另一方面，「各方法的 λ 量級完全不同」這件事讓持續學習的比較很容易失準，2019 年之後的論文多半明確交代超參數的選法（例如 Chaudhry 等人在 A-GEM 論文提出的協定：只用前 3 個任務選超參數），或報告多個 λ 下的整條取捨曲線，而不是只報一個點。

本章重點

  • MAS 的重要度：輸出 L2 範數平方 ‖F(x)‖² 對參數的梯度絕對值，對資料平均。不需要 label；作業要求 global 版（只用最後一層輸出），論文的 local 版對每層輸出各算一次。
  • 本 repo 的 TODO：loss = output.pow(2).sum(dim=1).mean()、loss.backward()、precision_matrices[n].data += p.grad.abs() / num_data。報告貼這一段（methods/mas.py 第 53–58 行）。
  • 先對 batch 平均再取絕對值只讓 MAS 變小 1.8 倍（EWC 是 111 倍），因為 ‖F(x)‖² 的梯度不會互相抵消；MAS 的重要度是 EWC 的約 90 萬倍，但兩者重要度的 Spearman 相關 0.861。
  • λ 掃描：0.001 → 74.61、0.01 → 79.14、0.1 → 83.88、1 → 78.66。λ 越大對角線越低（98.22 → 88.57）；λ = 1 時舊任務最後的平均反而下降。五個種子 83.07 ± 0.77。
  • MAS 在第 0 章贏，主要是懲罰項的強度大得多，不是重要度估得比較好；公平比較要先用同樣的程序選 λ（第 8 章）。

自我測驗

1. 投影片問：MAS 需不需要 label？從程式哪一行可以確定？

不需要。TODO 第 54 行只用到 output（模型對輸入的輸出），整個 calculate_importance 裡沒有任何地方用到 data[1]。對照 EWC 的第 56 行 label = data[1].to(self.device)。

2. 如果 TODO 留著 pass，MAS 會變成什麼？

重要度只剩「全 0 加上前面的 guard」，而前面的 guard 也都是 0，所以重要度永遠是 0，懲罰項恆為 0：等於一個 λ = 0.1 的 baseline。但它和真正的 baseline 數字不會完全一樣，因為 MAS 在 train.py 裡排在第三個跑，用到的亂數不同；另外每個任務結束時仍會走過一次訓練資料做 forward，這會從全域產生器抽亂數（第 2 章 2.6 節），也讓它和 baseline 的亂數流不同。這題是推論，本書沒有實際跑。

3. 把 TODO 的 p.grad.abs() 改成 p.grad ** 2，重要度會變大還是變小？

不一定。梯度絕對值大於 1 的參數，平方後變大；小於 1 的變小。5.3 節量到 MAS 重要度的最大值約 70（已經是對 469 個 batch 平均後），個別 batch 的梯度有很多大於 1，也有很多遠小於 1，平方會讓分布變得更集中在少數參數上。這已經不是 MAS 的定義了。本書沒有實際跑這個寫法。

4. λ 從 0.1 調到 1，BWT 幾乎沒變（−12.32 → −12.39），ACC 卻從 83.88 掉到 78.66。為什麼？

BWT 衡量的是「最後 − 剛學完」。λ = 1 時舊任務被拉得更緊，但每個任務剛學完時就比較差（對角線平均 88.57 對 93.74），所以「剛學完」與「最後」都下降，差值不變。ACC 是最後的絕對水準，兩邊都低就掉了。這是只看 BWT 會被誤導的例子（第 2 章 2.5 節）。

5. 第 0 章 MAS 的 λ 是 0.1，EWC 是 100。哪一個方法的懲罰項比較強？

MAS。重要度的量級差太多：同一個模型上 MAS 的重要度總和約 41 萬、EWC 約 0.45（5.3 節），懲罰項約是 λ × 重要度 × 參數變動平方，MAS 的 λ × 重要度大約是 EWC 的 900 倍。λ 的數字本身不能拿來比較兩個方法的強弱。
