這一頁是全書的設計圖，列出每一章對應哪些檔案、要回答什麼問題、用哪些實測數字。2026-10-09 經使用者核可。寫作途中如果發現大綱和程式不符，以程式為準，並回頭修改這一頁。

寫法

  • 每一章都對應真實的檔案與函式，程式碼逐字引用並標注 檔名:行號，行號以 commit 99b79fe 為準。
  • 具象先於抽象：先看 tokenizer 把一句話切成什麼，再談視窗；先把模型答錯的題目攤開來看，再談後處理的規則。
  • 每一個數字都在本機實測，原始紀錄在 docs/tools/hw07_runs.jsonl。「改 X 會怎樣」的題目一律實際跑過，只靠推論、沒有跑的會註明。
  • 同一份程式跑兩次，結果就不一樣（第 0、3 章）。所以實驗一律開決定性模式，每種設定跑 3 個種子，報平均與範圍；差距小於種子之間的差距時，不下「變好了」的結論。
  • 只報驗證集（dev）的 Exact Match。Kaggle 的基準線是測試集上的數字，而測試集沒有答案，所以本書不宣稱「過了哪條線」。使用者 2026 年在 Kaggle 實際交過的分數會當成史料引用。
  • 新名詞在全書第一次出現的地方解釋。遇到 2022 年的寫法已經過時，就加「現在的做法」框。
  • 圖表的顏色代表角色，全書一致：原版、LR 衰減、隨機視窗、換模型 1、換模型 2、換模型 3、換模型 4。
  • 最後一章是總結章（題庫、名詞對照、速查），不寫附錄。全書使用繁體中文與台灣用語。

讀程式找到的問題（各章實測）

#問題位置章
1from transformers import AdamW 在 transformers 5 已刪除。舊版的預設 eps 是 1e-6、weight decay 是 0，eps 加在偏差修正之前，和 torch.optim.AdamW（eps 1e-8、weight decay 0.01）不同；直接換成 torch 版會改變結果notebook、legacy_adamw.py3
2設了種子、也設了 cudnn.deterministic，同一份程式跑兩次，100 步後權重就不同，dev EM 在 0.416–0.464 之間train.py 的 same_seeds0、3
3訓練視窗一律把答案放在中央，評估視窗卻是從頭依序切；模型可能學到「答案在中間」dataset.py 訓練分支2、6
4doc_stride = 150 等於視窗長度，視窗之間沒有重疊；dev 有 74 題的答案被切在兩個視窗之間，怎麼預測都答不對dataset.py2、4
5答案用 tokenizer.decode 還原，[UNK]（英文字母、罕用字）與併在一起的數字還原不回原文；dev 44 題（1.07%）postprocess.py1、4
6start 與 end 各自取最大值，可能 end 在 start 之前（取出空字串）或答案長得不合理postprocess.py4
7變數叫 max_prob，實際加總的是 logits，不是機率；不同視窗的 logits 尺度不一定可比postprocess.py4
8問題超過 40 個 token 會被截掉（dev 114 題）；101／102 寫死，換模型時要確認詞表相同dataset.py1、7
9訓練 acc 是「在含答案的視窗裡 start、end 都對」，和 dev EM 量的不是同一件事train.py3
10fp16 的寫法是 accelerate==0.2.0 的 Accelerator(fp16=True)，新版已改成 mixed_precision="fp16"；本機 .venv 沒有裝 acceleratetrain.py7
11測試集有 1,464 題來自語音辨識的文字（ODSQA），有錯字；dev 沒有這種題目，所以 dev 的分數不能直接推到 Kagglehw7_test.json0
12註解說存檔會得到 pytorch_model.bin，新版 transformers 存成 model.safetensorstrain.py0
