HW07　BERT 抽取式問答：從一篇文章裡，框出回答問題的那一段

給模型一篇繁體中文文章和一個問題，答案一定是文章裡的一段連續文字，模型要指出這段文字從第幾個字開始、到第幾個字結束。這份作業拿已經預訓練好的 BERT 來微調，重點不在模型本身，而在模型前後的處理：文章太長要切成視窗，答案要從 token 換回原文，視窗之間要比較誰的答案比較可信。書中每一段程式碼都逐字取自本 repo，每一個數字都是在本機實際跑出來的。

先說在前面：用現在的眼光讀 2022 年的作業

這份作業出自 2022 年春季的課程。原版是一份 Colab notebook，指定 transformers==4.5.0，資料讀取、視窗切割、訓練迴圈、評估都已經寫好，留下四個 TODO：學習率衰減、doc_stride、前處理、後處理。本 repo 把 notebook 拆成幾個 .py 檔，2026 年在本機用當時的套件版本重新跑過一遍。動手之前，先分四個層次把 2022 年和現在的差異講清楚。

第三層：方法——抽取式問答被生成式問答取代，BERT 換了工作

2022 年，「在文章裡框出答案」是閱讀理解的標準做法：SQuAD、DRCD 這類資料集都是這個格式，排行榜上的冠軍都是 BERT 家族。到了 2026 年，同樣的需求大多交給大型語言模型：把文章和問題放進提示，讓模型用自己的話回答；文章太長或太多時，先用檢索找出相關段落再交給模型，也就是 RAG（retrieval-augmented generation）。

現在的做法：BERT 退到檢索那一端

BERT 這類只有 encoder 的模型沒有消失，而是換了位置。RAG 的第一步是「從一堆文件裡找出可能有答案的段落」，負責這一步的 embedding 模型與 reranker（重新排序器），大多仍是 BERT 的後代，因為它們看完整段文字只需要一次 forward，比生成式模型快得多。抽取式問答本身也還用在一些需要「答案一定逐字出自原文」的場合，例如合約、病歷的欄位擷取，因為它不會編出原文沒有的字。本作業的幾個觀念也直接搬到了 RAG：文章切成重疊的塊（chunk）就是這裡的 doc_stride，塊太大或太小都會把答案切斷；從多個塊的分數裡挑答案，就是這裡的後處理。

第四層：觀念——沒有過時，這是本書的主體

tokenizer 把文字切成什麼、切壞了怎麼救；固定長度的模型怎麼處理比它長的輸入；訓練資料的擺法會不會讓模型學到不該學的捷徑；模型只輸出兩排分數，「答案」其實是後處理的規則決定的；預訓練模型之間差在哪裡、換一個模型為什麼可能比調十個超參數還有用。還有一件和問答無關、每個深度學習專案都會遇到的事：在 GPU 上，同一份程式、同一個種子，跑兩次可能得到不同的結果；一個改良「贏了」之前，要先知道種子之間本來就差多少。

最大的兩個進步都不在模型本身：隨機視窗（訓練時不要總把答案放在視窗中央）+15 個百分點；評估的 stride 與後處理，不重新訓練就讓範例的模型從 0.416 到 0.632。學習率衰減 +10.6（其中 7.8 來自學習率減半）。沒有用的：多訓練幾個 epoch、換 AdamW 的實作、轉小寫。fp16／bf16 讓訓練快 2.7 倍，大模型快 3.3 倍。另外兩個貫穿全書的發現：同一份程式在 GPU 上跑兩次結果不同（第 0、3 章），以及範例設定下種子之間就差 6.6 個百分點，所以每個比較都跑 3 個種子。

章節

  1. 第 0 章　全貌：一篇文章、一個問題、兩排分數

    任務、資料、Exact Match、模型總覽（BERT-base 加問答頭）；跑一次原版；同一份程式跑兩次分數就不同。

  2. 第 1 章　Tokenizer：中文被切成什麼

    一字一個 token、英文與數字的 WordPiece、[UNK]、特殊符號 101／102、字與 token 的對應。

  3. 第 2 章　Dataset：視窗怎麼切

    為什麼要切視窗；訓練把答案放中央、評估依序切；doc_stride 把答案切成兩半的 74 題。

  4. 第 3 章　模型與訓練迴圈

    start／end logits 與 loss；兩種 AdamW；訓練 acc 0.74、dev 0.42 的落差；GPU 的非決定性。

  5. 第 4 章　評估與後處理

    範例的 evaluate 錯在哪；end 在 start 之前、長度上限、從原文取答案；同一個模型只改後處理能差多少。

  6. 第 5 章　Medium：學習率與訓練長度

    線性衰減、1／2／3 個 epoch、三個種子的範圍。

  7. 第 6 章　Strong：前處理

    答案永遠在中央的捷徑；隨機視窗；預測位置的分布。

  8. 第 7 章　換預訓練模型

    RoBERTa-wwm、MacBERT、CKIP、RoBERTa-large；不訓練直接用；fp16／bf16 與梯度累積。

  9. 第 8 章　總結

    全書實驗總表、題庫、名詞對照、速查表。

怎麼跑

所有指令都在 HW07/ 目錄下執行，使用 repo 共用的 .venv（Python 3.12、torch 2.11、transformers 5.18）。資料檔 hw7_train.json、hw7_dev.json、hw7_test.json 從 Kaggle 的壓縮檔解開後放在同一個目錄。

$ cd HW07
$ ../.venv/bin/python train.py    # 訓練 1 個 epoch、評估 dev、存到 saved_model/
$ ../.venv/bin/python test.py     # 讀 saved_model/，寫出 result.csv

需要逐位元重現的時候（例如比對兩份程式），用決定性模式包住執行：

$ CUBLAS_WORKSPACE_CONFIG=:4096:8 PYTHONPATH=. ../.venv/bin/python ../docs/tools/hw07_det.py train.py
