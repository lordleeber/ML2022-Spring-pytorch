A.5　repo 問題清單（8 項）

讀程式時整理出的程式與論文、投影片不一致之處。第 1–6、8 項本 repo 刻意照原版保留，不修改；第 7 項是外部資源消失，repo 已經加了替代路徑。完整的說明在教學大綱〈讀 code 不盡信文件〉與各章。explain_cnn.py 寫死 .cuda() 是本 repo 刻意的設計，不列為問題（第 0 章 0.3 節）。

#問題影響（實測）章節
1LIME 的 start_label=1 與 lime 0.2.0.1 的編號差一號：最後一塊 superpixel 永遠不被解釋，特徵 0 是假特徵改成 0 後圖 0 的 R² 0.842 → 0.8617，前 5 名是同一組塊、編號各減 12.9
