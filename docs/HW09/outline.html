讀 code 不盡信文件：預定寫進教材的發現

第 1–6、8 項是本 repo 刻意照原版保留的地方；第 7 項是外部資源消失，repo 已經加了替代路徑，但原作業的圖仍然無法重現。教材會解釋每一項、用實測數字說明影響，但不改程式。

  1. LIME 的 start_label=1 與 lime 0.2.0.1 的編號差一號：最後一塊 superpixel 永遠不會被遮、也不會出現在解釋裡，LIME 的特徵（每塊 superpixel 是一個特徵）0 號是對應不到任何像素的假特徵（第 2 章）。
  2. LIME 的 predict 回傳 logits 而不是機率，get_image_and_mask 的 min_weight=0.05 門檻意義因此改變：圖 0 的 |權重| ≥ 0.05 用 logits 時有 83 塊，換成機率只剩 13 塊（第 2 章）。
  3. SmoothGrad 的雜訊標準差是 (0.4 ÷ 範圍)²，論文是 0.4 × 範圍（第 3 章）。
  4. Integrated Gradients 少乘 (x − baseline)，baseline 固定為全黑，α 不含 1（第 5 章）。
  5. Filter visualization 從原圖而不是白雜訊出發（投影片 p.10 寫 start from white noise），而且沒有把 x 限制在 [0, 1]（第 4 章）。
  6. Saliency map 對 CE loss 而不是類別分數取梯度（投影片 p.8 寫 gradient of output category），模型極度自信時梯度接近 0（第 3 章）。
  7. hw9_bert.zip 下架，Q25–27 無法重現原作業的圖（第 6 章）。
  8. bert_embedding.py 句 5「發振」是錯字、句 1 的括號全形半形混用，原版如此（第 7 章）。

另外，三支腳本都寫死 .cuda()、沒有 CPU 的替代路徑，這是本 repo 刻意的設計，書中只在第 0 章說明執行環境，不把它當成問題或練習。
