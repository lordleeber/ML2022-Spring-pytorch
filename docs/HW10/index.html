ML2022 Spring · HW10 讀碼教材

HW10　對抗攻擊：
每個像素只改 8，騙過看不見的模型

給你 200 張 CIFAR-10 的小圖，每個像素最多只能改 8（0–255 的尺度），人眼幾乎看不出差別，目標是讓助教手上的分類模型認錯越多越好。你看不到助教的模型，只能拿公開的預訓練模型當「代理」，在代理上算梯度產生雜訊，再賭這些雜訊也能騙過別的模型。書中每一段程式碼都逐字取自本 repo，每一個數字都是在本機實際跑出來的。

先說在前面：用現在的眼光讀 2022 年的作業

這份作業出自 2022 年春季的課程。原版是一份 Colab notebook：資料讀取、評估、FGSM 與 I-FGSM、存檔與壓縮都寫好了，留下三個 TODO——MI-FGSM 的動量、ensemble 模型的 forward、報告題的 JPEG 壓縮。本 repo 把 notebook 拆成幾個 .py 檔、補上三個 TODO，2026 年在本機重新跑過一遍。動手之前，先分四個層次把 2022 年和現在的差異講清楚。

第三層：方法——攻擊的對象從圖片分類器換成了大型語言模型

2022 年，對抗攻擊的教科書例子就是這份作業：一張圖加上看不出來的雜訊，分類器就認錯；用公開模型產生的雜訊，常常也能騙過沒見過的模型（轉移性）。投影片上的方法——FGSM（2015）、I-FGSM（2017）、ensemble 攻擊（2017）、MI-FGSM（2018）、DIM（2019）——都是那幾年的成果。

現在的做法：同一套觀念，搬到了 LLM 的越獄與防禦

2026 年的課程（ML2026 HW1「LLM Malicious Instruction Defense」）已經不攻擊圖片分類器，而是處理大型語言模型的越獄：在提示裡加一段看似無意義的字串，讓模型說出它本來會拒絕的內容。最有名的 GCG 攻擊（2023）做的事和本作業幾乎一樣——在一個開源模型（白箱代理）上對輸入的 token 取梯度、一步步改，產生的字串再拿去攻擊看不到內部的商用模型（黑箱），也常常有效。防禦這一端，JPEG 壓縮這類「把輸入先洗一遍」的被動防禦，對應到 LLM 就是把提示改寫、過濾後再交給模型；而「攻擊者知道你有防禦，就把防禦算進攻擊裡」這個教訓（第 7 章），在 LLM 的安全評估裡同樣成立。圖片分類器這一端，真正能抵抗攻擊的做法是對抗訓練（adversarial training）與可證明的穩健性（certified robustness），本作業沒有涵蓋。

第四層：觀念——沒有過時，這是本書的主體

對輸入取梯度，而不是對權重；在一個限制（L∞ 球）裡找讓 loss 最大的點；為什麼只用梯度的正負號；在代理模型上「太用力」反而騙不過別的模型——攻擊也會過擬合，而防止過擬合的工具和訓練模型時一樣：ensemble、資料增強、動量、不要把代理練得太好。還有兩件和攻擊無關、每個深度學習專案都會遇到的事：在 GPU 上，同一份程式跑兩次結果可能不同；程式印出的分數，不一定是交出去的那個東西的分數。

預備知識

  • Python 與 PyTorch 的基本用法：nn.Module、DataLoader、loss.backward()、requires_grad。
  • CNN 影像分類的概念（卷積、BatchNorm、ResNet 的殘差連接）。讀過 HW03 的教材會很順。
  • softmax 與 cross entropy。對輸入取梯度在 HW09 的 saliency map 也出現過，讀過更好。

章節

  1. 第 0 章　全貌：200 張圖、ε = 8、看不見的模型

    任務、黑箱與代理、評分與基準線；模型總覽（resnet110_cifar10）；跑一次原版；同一份程式跑兩次圖片就不同。

  2. 第 1 章　資料與 ε 的換算

    ToTensor 與 Normalize 之後 ε 變成多少；資料夾順序與類別；還原、四捨五入、存檔；印出的準確率和 PNG 的差距。

  3. 第 2 章　FGSM：對輸入取梯度，只走一步

    為什麼取正負號；線性假說；ε 的掃描；GPU 的非決定性。

  4. 第 3 章　本機黑箱：怎麼量轉移性

    pytorchcv 的 85 個模型；代理與受害者分家族；40 個代理各自的轉移表。

  5. 第 4 章　I-FGSM 與代理模型的過擬合

    多走幾小步；白箱全錯、黑箱只降一點；步數與步長。

  6. 第 5 章　Ensemble 與訓練不足的代理

    四種聚合方式；代理的數量與多樣性；自己訓練的早期 checkpoint 當代理（paper B）。

  7. 第 6 章　MI-FGSM 與 DIM

    動量與輸入多樣化；和 ensemble 疊加的最強組合。

  8. 第 7 章　防禦：JPEG 壓縮

    報告題；壓縮率 70 等於品質 31；壓縮強度掃描；攻擊者知道有防禦時。

  9. 第 8 章　總結

    全書實驗總表、題庫、名詞對照、速查表。

怎麼跑

所有指令都在 HW10/ 目錄下執行，使用 repo 共用的 .venv（Python 3.12、torch 2.11、pytorchcv 0.0.74）。200 張圖從 Kaggle 的壓縮檔 ml2022spring-hw10.zip 解開成 HW10/data/。

$ cd HW10
$ ../.venv/bin/python hw10.py      # 量原圖、跑 FGSM 與 I-FGSM，寫出 fgsm/、ifgsm/ 與兩個 .tgz
$ ../.venv/bin/python report.py    # 視覺化與報告題（需要 imgaug，見第 7 章）

需要逐位元重現的時候（例如比對兩份程式），用決定性模式包住執行：

$ CUBLAS_WORKSPACE_CONFIG=:4096:8 ../.venv/bin/python ../docs/tools/hw10_det.py hw10.py
