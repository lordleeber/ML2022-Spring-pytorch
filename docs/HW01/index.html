ML2022 Spring · HW01 讀碼教材

HW01　COVID-19 確診率預測

用一個不到 300 行的 PyTorch 專案，把「讀資料 → 切分 → 建模 → 訓練 → 預測」整條深度學習流程從頭走一遍。每一段程式碼都逐字取自本 repo，每一個數字都是在本機實際跑出來的。

先說在前面：用 2026 年的眼光讀 2022 年的作業

這份作業出自 2022 年春季的課程，本書則是在 2026 年、用當下的硬體與套件把它重新跑過一遍。四年在深度學習領域很長，所以動手之前先把話講清楚：哪些東西已經過時、哪些沒有。分三個層次看。

第一層：環境與 API——已經過時，本書已修到能跑

課程當年指定 PyTorch 1.13 搭 CUDA 11.6。這組版本在新一代顯卡（本機的 Blackwell）與 Python 3.12 上根本裝不起來，所以本 repo 已改用 PyTorch 2.11 搭 CUDA 12.8（第 0 章細說）。HW01 的程式碼本身很單純，換版本後不必改任何一行就能跑。同一個 repo 的其他作業就沒這麼幸運：HW07 用到的 transformers.AdamW 已被移除、HW08 的 torch.load 碰上 PyTorch 2.6 起的新預設 weights_only=True、HW05 依賴的 fairseq 已停止維護。這一層是「改幾行就好」的過時。

第二層：方法——部分過時，這是最值得知道的一層

HW01 用一個小型神經網路（DNN）做迴歸。但它的資料是一張只有 2,699 列的表格，而在小型表格資料上，神經網路通常不是第一個該拿出來的工具。今天的標準做法是：先建立簡單的基準（baseline），再決定要不要上神經網路；表格資料上常用的強基準是梯度提升樹（gradient boosting，例如 XGBoost、LightGBM）。

說「簡單方法可能更好」不能只憑印象，所以我們在和範例程式完全相同的驗證集上，量了三個完全不需要神經網路的做法：

$ cd HW01
$ ../.venv/bin/python -c "
import pandas as pd, numpy as np
from utils import train_valid_split
from config import config
tr = pd.read_csv('covid.train.csv').values
tr, va = train_valid_split(tr, config['valid_ratio'], config['seed'])
def linreg(cols):
    X = np.c_[tr[:, cols], np.ones(len(tr))]
    w = np.linalg.lstsq(X, tr[:, -1], rcond=None)[0]
    pred = np.c_[va[:, cols], np.ones(len(va))] @ w
    return ((pred - va[:, -1]) ** 2).mean()
print('copy day 4      ', round(((va[:, 101] - va[:, -1]) ** 2).mean(), 3))
print('linreg 4 tp cols', round(linreg([53, 69, 85, 101]), 3))
print('linreg 116 cols ', round(linreg(list(range(1, 117))), 3))

範例程式訓練了 1,883 個 epoch 的神經網路，輸給了「抄昨天的數字」。這不代表神經網路沒用——第 7 章會看到，把特徵選好、優化器換掉，DNN 可以大幅進步——而是說明兩件 2022 年的範例程式沒有教、但今天被視為基本功的事：

  • 先做 baseline。沒有 baseline，你不會知道 1.661 是好是壞。
  • 驗證方式要符合資料的性質。第 1 章會發現這份資料是時間上的滑動視窗，隨機切分會讓驗證集「偷看」到訓練資料；今天的做法是按時間切分。上表四個方法用的是同一個隨機切分，彼此比較是公平的，但數字整體偏樂觀。

第三層：觀念——沒有過時，這是本書的主體

Dataset 與 DataLoader、模型的 forward、訓練迴圈的五個步驟、train／eval 模式、保存最佳模型、early stopping、用驗證集挑模型——這些在 2026 年寫 PyTorch 時一模一樣。本書花最多篇幅的就是這一層，你在這裡學到的東西，換成任何新模型都用得上。

本書怎麼處理「過時」

程式碼保持課程原貌，只修到能在新環境跑（方便你對照課程影片與投影片）。每一章遇到已經不是今天主流的寫法時，會加一個「現在的做法」說明框；第 7 章則把上面這張表延伸成完整的比較。

這本教材在教什麼

這是台大李宏毅老師《機器學習 2022 Spring》第一份作業（HW01）的讀碼教材。作業要做的事很單純：給你美國某一州連續 5 天的問卷統計（有多少人有類 COVID 症狀、多少人戴口罩、多少人感到焦慮……），以及前 4 天的確診陽性率，請你預測第 5 天的陽性率（tested_positive）。輸出是一個實數，所以這是一個迴歸（regression）問題。

官方給的範例程式（sample code）原本是一份 Colab 筆記本。本 repo 把它拆成六個獨立的 .py 檔，每個檔案只負責一件事，讓「哪一段程式在流程的哪一步」一目了然。這本教材就順著資料在這六個檔案之間流動的順序，一章講一段。

你會學到

PyTorch 的 Dataset／DataLoader、nn.Module、訓練迴圈五步驟、train／eval 模式、存最佳模型、early stopping、TensorBoard。

你會看到

真實 CSV 的 118 個欄位怎麼排、每個 epoch 跑幾個 batch、模型共有幾個參數——全都實際算過、跑過。

你會帶走

一份能在新顯卡上跑的環境、一張從 sample code 往 strong／boss baseline 改的路線圖，和三級練習題。

預備知識

  • Python：會寫函式與 class、看得懂 list 切片與 f-string。
  • NumPy 基礎：知道二維陣列 a[:, -1] 是「每一列的最後一欄」。
  • 機器學習概念：聽過「損失函數（loss）」與「梯度下降（gradient descent）」就夠了。不懂 PyTorch 沒關係，本書從零講起。
  • 指令列：會 cd 和執行指令即可。

章節目錄

  1. 第 0 章　任務與環境：先讓它跑起來

    作業要預測什麼、為什麼新顯卡要用 cu128、實際跑一次 train／predict 並逐行解讀輸出、六個檔案的分工地圖。

  2. 第 1 章　解剖 COVID 資料

    118 欄 = id + 37 州 one-hot + 16 指標 × 5 天。用 pandas 親眼看數值的範圍與分布。

  3. 第 2 章　切分、特徵與可重現性

    same_seed、train_valid_split、select_feat：2699 筆如何變成 2160／539，以及被悄悄當成特徵的 id。

  4. 第 3 章　Dataset 與 DataLoader

    COVID19Dataset 的三個方法，batch、shuffle、pin_memory，每個 epoch 為什麼是 9 個 batch。

  5. 第 4 章　模型：117 → 16 → 8 → 1

    nn.Sequential 堆出的小型全連接網路、參數量實算 2,033、squeeze(1) 的形狀魔術。

  6. 第 5 章　訓練迴圈

    本書最重的一章：zero_grad → forward → loss → backward → step、驗證、存最佳模型、early stopping、TensorBoard。

  7. 第 6 章　預測與輸出 pred.csv

    載回最佳權重、在測試集上推論、把 1078 筆預測寫成提交格式。

  8. 第 7 章　從 sample code 往上爬

    作業提示（特徵選擇、換架構與 optimizer、L2 正則化）對應到程式碼的哪裡，加上入門／進階／挑戰三級題庫。

  9. 附錄　名詞對照與速查

    中英名詞對照、超參數速查、函式速查、常用指令。

學習路徑

建議照章節順序讀：第 0 章先讓程式跑起來，你手上就有一組「正確答案」可以對照；第 1 章看清楚資料長什麼樣，後面每一個 shape、每一個維度你都知道從哪來。第 2～6 章完全依照資料在程式裡的流向排列，讀完第 6 章就走完一整圈。第 7 章是動手改的起點。

全書的圖都用同一套配色，顏色代表「這一步是誰在做、資料在哪裡」：

CPU 端的資料（pandas／NumPy／Dataset） GPU 上的運算（模型、tensor 計算） 磁碟上的檔案（csv、model.ckpt、runs/） 控制與超參數（config、迴圈控制）
