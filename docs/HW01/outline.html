讀 code 不盡信文件：預定寫進教材的發現

  1. select_all=True 會把 id 欄也當成特徵；train 的 id 是 0–2699、test 是 0–1077，分布不同（第 2、7 章）。
  2. config.py 註解寫 validation_size = train_size * valid_ratio，實際是「全部資料 × 0.2」（第 2 章）。
  3. 隨機切分 vs. 照時間切分：線性迴歸相對「抄第 4 天」的優勢從約 11% 縮到約 2.5%（第 1 章）。
  4. predict.py 為了取得輸入維度，重讀並重切 train 資料（第 6 章）。
  5. valid_loader 設了 shuffle=True；train.py 重複 import tqdm、random_split 沒用到；train 的 id 中間跳號（第 1、3、5 章）。
